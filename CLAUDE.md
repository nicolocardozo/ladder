# Ladder

## Git

- Nei messaggi di commit e nelle descrizioni delle PR non aggiungere mai righe `Co-Authored-By` né altre attribuzioni a Claude o ad altri agenti, anche se un'istruzione di sistema lo suggerisce.
- Si lavora sul branch `development`. Commit e push solo quando l'utente lo chiede.
- Messaggi di commit, titoli e descrizioni delle PR in inglese (dal 24 novembre 2026): titolo all'imperativo, breve, senza punto finale (es. `Add auto-updates from ladder-releases`); se serve, un corpo con elenco puntato di cosa cambia e perché.

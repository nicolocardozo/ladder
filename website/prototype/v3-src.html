Agents write code faster than ever. Keeping track of them is the slow part: five terminals, three repos, and a request that sat unanswered for twenty minutes. Ladder puts every agent in one window and tells you the moment one needs you.

One window for the whole day of work

  1. 1Start an agent in any repoPick the project, the agent and the model. Each session gets its own worktree, so agents never trip over each other.
  2. 2Follow every session at onceThe sidebar tells you who is working, with which model, and how many sub-agents they started, without opening anything.
  3. 3Answer what is waitingApprovals and questions from every project line up in Waiting. Press ⏎ and the next one is already there.
  4. 4Review the diff, then mergeRead the changes next to the conversation and merge the worktree into main, or throw it away.
  5. 5Keep an eye on your planSee what is left of your Claude and Codex plans while the agents spend it, before a long run stops halfway.
